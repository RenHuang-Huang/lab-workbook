# 工作簿輸出

Windows 64 位元桌面程式。唯讀擷取本機 Access 檢驗資料，依可調整的區域、簡稱、套組與流水號規則產生 A4 工作簿 PDF。

## 安裝及更新

1. 在 [Releases](https://github.com/RenHuang-Huang/lab-workbook/releases) 下載 `lab-workbook-年月日-v版號-windows-x64.zip`，完整解壓縮至可寫入的資料夾。不要只複製 EXE。
2. 雙擊 `工作簿輸出.exe`。第一次使用請在系統設定選擇 Access 資料庫及輸出位置，按「測試連線」。
3. 若已有舊版，關閉舊程式後將新版完整覆蓋到原程式資料夾，或在系統設定按「匯入設定」並選取舊版程式資料夾。**不要刪除原資料夾或其設定。**
4. 後續更新：系統設定 →「檢查並更新程式」。有正式新版時會列出版本和下載大小，確認後儲存設定、關閉主程式，交由獨立工具下載、驗證、替換及重新啟動。
5. 更新工具在安裝資料夾的 `.update-backups/` 保留程式備份；下載或替換失敗會提示，已開始替換的更新會嘗試還原。若斷電或工具被強制終止，下次啟動會嘗試復原，也可手動執行 `修復未完成更新.cmd`。請不要刪除未完成更新的備份。

更新需要網路、安裝資料夾寫入權限及足夠備份空間；請先關閉同資料夾的其他工作簿視窗。程式及更新工具尚未購買程式碼簽章憑證，Windows 或現場防毒軟體可能要求確認。

## 本機設定與資料

列印設定 →「項目列印與簡稱」→「近三年使用統計」可指定截至日期，整理往前連續三年的套組／單項使用次數。每張原始檢驗單的同代碼只計一次，不受工作簿併單影響；預設排除套組展開的單項，取消勾選即可用同份結果重新計算。清單依目前已儲存的列印區域分類，各區按次數遞減，可搜尋、篩選與點欄名排序，並匯出兩種清單的完整 CSV／JSON。統計在本機背景執行，不讀姓名、病歷號、身分證或檢驗值。

展開子項只在 `LCHK_MKEY` 對上同張單已登錄的 `G` 套組代碼時排除；同碼另外獨立加開仍計一次。找不到對應套組的非空關聯保留計數，標為待核對；缺少類型／代碼的明細另列數量。套組同碼有多個診所定義時合計一次並列出名稱，不按字典定義數重複累加。統計採開單工作日 `LCHK_INDATE`，不是就醫日期。資料庫若缺少早年的紀錄，統計僅涵蓋目前檔案中存在的資料。

`print_settings/settings.json` 與 `layout_settings.json` 的 `updated_at` 記錄實際儲存變更的時間（ISO 8601，含時區）；`layout_settings.json.item_updated_at` 以單項代碼或 `G:套組代碼` 分別記錄項目最後修改時間。項目設定清單新增「最後更新」欄，匯出的 JSON 校對清單也包含日期。單純開啟、更新快取或升級不刷新修改時間；舊設定沒有日期時顯示「尚無紀錄」。匯入已有日期的項目設定時保留来源修改時間；沒有日期的實際變更記錄本次套用時間。JSON 清單最外層的 `updated_at` 是快取重建時間，`settings_updated_at` 才是列印設定最後更新時間。

側邊欄「病例查詢」可選工作日期、輸入工作號（可省略前置零）查詢原始套組、單項、檢驗值及目前列印區域／代碼。套組可展開子項；停印項目也會顯示，未登錄子項標明未登錄，不補值。新查詢依同單套組來源關聯展開，並顯示套組內的列印選擇；另加開同碼保留為單項。舊查詢快照缺少關聯時，才按字典顯示待核對的成員。來源明細統計不重複計數。

符合目前併單規則的其他原單一起顯示，保留工作號、各單結果與查詢命中／併單來源標記；排除工作號及缺少病歷號／姓名的單不合併。同工作號若跨部門重複，列出各自的命中單。數值原樣呈現，不進行醫療判讀；選取項目可查看完整的主值、值 2、值 3、結果文字與單位。這些查詢只在本機執行，結果不存入進度檔、設定或診斷紀錄，查詢暫存檔在讀取完成後清除。程式不查詢身分證欄位。

列印設定的「併單與同上符號」可選擇置左、置中、置右，預設 20 pt、加粗、置中，並可保留生化區的 `@`。頁首 Glucose AC&PC 填入格依實際登錄項目選取；同筆有 AC 或 PC 都只列一格，沿用工作簿顯示的工作號。

「欄位與分區」可調整三組機器流水號的上標、字級與各自顏色。預設不上標、14 pt，e411／mab 紅色、HbA1c 藍色。密集內容會依空間縮小。升級補齊新增選項，保留已儲存的自訂值。

流水號與項目直接相接，例如 `1sAg`、`HbA1c1`、`mab2/`。生化、CBC／尿液、外送、e411、其他區皆每欄最多三列，第四項往下一欄排；一般、自動列高及強制輸出皆遵循。固定位置選 1～3，排列順位仍可選 1～10；舊位置 4、5 保留設定，輸出時往後補位。超出欄寬或總容量仍會提示確認強制縮字，不省略項目。

項目文字以設定字級為目標，按實際字形高度縮放，包含下伸筆畫、中文及上標流水號。各子區域的起點仍對齊；同一筆右側沒有內容的空位可供文字使用，避免其他筆較密集時，把單獨的 Ferritin 等項目也切窄縮小。不跨入已有項目、取消空區遞補的保留欄或其他列印區域。仍不足時維持原本的強制輸出確認，設定字級與同子區域一致字級的規則不變。

同一筆「其他區」依實際使用欄數平均分配寬度，每欄最多三列；未勾選空區遞補的中間空欄仍保留。換到第二欄或更多欄時，所有項目名稱採能容納全部欄位的共同字級，右欄不因內容較少而單獨放大。項目、流水號及填寫底線一起計算欄寬，先縮短底線的預留長度再縮字，剩餘空間仍畫滿底線；流水號仍依其獨立字級、顏色與上標設定呈現。此規則適用於固定二十筆、自動列高及強制輸出，不更動已儲存的列印設定。

「套組、單項、診所設定」可展開套組階層。父列設定套組名稱的列印代碼、區域及是否列印（是／否）；子列勾選是否列印，只作用於這個套組，不修改獨立單項或其他套組。同套組代碼的診所版本共用設定，階層仍分別列出來源成員。

選取子項即可勾選是否列印；父列另有「子項全部列印／子項全部不印」。修改列標黃，按「儲存全部修改」預覽項目名稱與差異後一次提交。搜尋與各欄篩選保留父子階層；子項的列印代碼、區域、位置和顏色沿用單項設定，是否列印獨立儲存在 `layout_settings.json.panel_children`。父套組與子項均記錄最後實際修改時間。

不再提供「跨區列印子項」。升級會將原來的跨區選擇轉成各子項的勾選值；已存的子項選擇優先。同名流水號子項預設不重複列印，流水號移到有列印的同代碼套組名稱旁，例如 `mab1/`；其他套組由勾選的流水號子項顯示，取消勾選不再強制列印。若沒有實際登錄同名子項，不補流水號；只隱藏所有子項且沒有套組承接流水號時，該組不編號。父列與子列同時勾選時，會依使用者設定分別列印。

每日資料以同張原單的 `LCHK_MKEY` 對應已登錄套組代碼判斷子項歸屬；另外獨立加開的同代碼保留，即使併單也不會被其他單的套組吞掉。只列印實際登錄資料，不以字典補缺項。舊工作進度若未保存套組來源，請重新從資料庫匯入當日資料。

- `preferences.json`：系統設定，包含資料庫位置、輸出位置與拆併單偏好。
- `print_settings/`：列印版面、字級、項目／診所簡稱、流水號及本機字典快取。
- `config_backups/`：設定變更及匯入時的備份。
- PDF 與工作進度檔留在使用者選定的本機輸出資料夾。

**GitHub 原始碼與公開安裝包不包含 Access 資料庫、病患紀錄、診所字典或使用者儲存過的設定。**首次啟動由程式內建預設值建立本機設定，現場規則須匯入或設定並核對。更新包不覆蓋既有設定、資料庫及輸出檔案。每日資料處理不呼叫雲端服務；更新功能只讀取固定 GitHub 倉庫的公開版本資訊及安裝包，不上傳檢驗資料。

缺少 Access 元件時，在系統設定的連線工具依指示安裝。安裝包附 Microsoft 官方 x86／x64 Access Runtime **線上安裝程式**，需要網路；程式會先核對雜湊及 Microsoft 簽章，保留官方安裝流程。Office 位元及既有安裝方式須相容。

## 開發

Python 3.12、Windows、Tkinter。安裝 `workbook/requirements.txt`，在專案根目錄執行：

```powershell
python -m workbook.app
python -m unittest workbook.test_updates workbook.test_config_store
```

應用程式可從乾淨原始碼啟動並建立本機設定；讀取 Access 需要相容的 ACE provider。公開測試使用人工資料；部分歷史測試依賴本機參考資料，這些資料不隨倉庫提供。

## 發行

1. 在 `workbook/version.py` 設定固定版本，格式 `YYYYMMDD-vN`。
2. 安裝 PyInstaller。先執行 `python scripts/fetch_runtime_installers.py` 取得並校驗 Microsoft 線上安裝檔，再執行 `python scripts/build_desktop.py --public`。
3. 測試產出的 EXE、獨立更新工具、設定保留及回復流程，並執行 `python scripts/audit_public.py`。
4. 推送經審查的原始碼；以同版號建立 GitHub Release，上傳 `lab-workbook-版號-windows-x64.zip`。必須先完成所有附件再發布 Release；自動更新只接受正式版本及 GitHub 提供的 SHA256。

`--settings-from` 只供本機延續設定的私用包，檔名標記 `LOCAL_ONLY`，不得上傳 GitHub。公開模式拒絕本機字典參數。不要提交 `output/`、`tmp/`、設定 JSON、分析資料、照片、檢驗單或資料庫。

更新保護包含：固定倉庫與檔名、TLS、GitHub SHA256、解壓縮容量限制、路徑／連結檢查、檔案清單校驗、保護本機設定、程式備份、更新日誌及安裝前後啟動檢查。雜湊用於偵測內容損壞；發行來源的信任仍依賴 GitHub 帳號及倉庫權限，維護者應啟用兩步驟驗證。
